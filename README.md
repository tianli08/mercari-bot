# Getting started

To run the project, make sure you have the [uv package manager](https://docs.astral.sh/uv/getting-started/installation/) installed

Once installed, in the repo directory, use the following command to create a virtual environment & install packages

```bash
uv sync
```

Next, activate your virtual environment:
```bash
source .venv/bin/activate
```

Finally, run with
```bash
python -m src.main
```
